# Projeto-gamezone
Site Game Zone desenvolvido em HTML, com foco em jogos, entretenimento e interface web.

# Sobre o projeto

O Game Zone Retro é uma página web criada para representar uma loja de jogos clássicos. A página apresenta alguns consoles e jogos retrô, além de uma tabela com os preços dos jogos disponíveis.

O projeto foi desenvolvido como uma atividade para praticar os conceitos básicos de criação de páginas utilizando HTML.

# Objetivo

O objetivo do projeto é criar uma página simples e organizada para uma loja de jogos retrô, apresentando:

- Nome da loja;
- Uma breve descrição;
- Imagem relacionada a jogos clássicos;
- Link para o Instagram;
- Lista de consoles disponíveis;
- Tabela com jogos e preços.

# Consoles disponíveis

- Nintendo (NES)
- Super Nintendo (SNES)
- Sega Genesis
- Atari 2600
